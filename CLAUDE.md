# Контекст проекта для Claude Code

Внутреннее приложение ежедневных отчётов. Команда — 14 инженеров и руководитель.
Главный принцип: намеренная простота. Один процесс, одна база, серверный рендеринг.
Не добавлять фронтенд-фреймворки, очереди, кеши и внешние сервисы без явной причины.

## Как устроено

- `app/models.py` — схема. Менять только вместе с новой миграцией в `alembic/versions/`.
- `app/services/reports.py` — вся бизнес-логика: разбор строк формы, валидация часов,
  окно редактирования, выборки за месяц. Роутеры логику не содержат.
- `app/routers/` — только HTTP: разбор запроса, вызов сервиса, рендер шаблона.
- `app/templates/` — Jinja2. Внешних CDN нет: сервер может стоять без интернета.
- `tests/test_smoke.py` — сквозной сценарий на SQLite.

## Правила

- Любое изменение схемы = новая миграция Alembic, автогенерацию проверять руками.
- Перед коммитом: `PYTHONPATH=. pytest -q`.
- Секреты только в `.env`, он в `.gitignore`. В коде и в коммитах паролей нет.
- Тексты интерфейса — по-русски, обычным языком, без канцелярита и заглавных букв в метках.
- Часы — `Decimal`, не `float`. Даты отчётов — `date`, без времени.
